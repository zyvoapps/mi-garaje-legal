# Mi Garaje by ZYVO — sitio legal público

Sitio estático para GitHub Pages de la aplicación Android **Mi Garaje by ZYVO**.

- `index.html`: portada legal
- `privacidad.html` / `privacy.html`: privacidad ES/EN
- `terminos.html` / `terms.html`: términos ES/EN
- `style.css`: estilos estáticos, sin seguimiento

**Importante:** no publicar aquí código fuente, APK privadas, registros reales de vehículos, respaldos, claves ni archivos de usuario.

Publicación sugerida: repositorio público separado `mi-garaje-legal`, rama `main` → **Settings > Pages > Deploy from a branch > main / (root)**. La URL de privacidad para Google Play debe apuntar directamente a `privacidad.html` y estar enlazada en la app.

Revisar contenido antes de activar publicidad, pagos, cuenta o sincronización.
